# 康家佳品｜悟空场景化实战培训

一套面向康家佳品的 16:9 网页 PPT。内容按“业务认知 → 工作机制 → 三个主场景 → 部门场景地图 → 现场实操 → 建设方法 → 课后行动”展开，共 38 页、建议讲解时长 120 分钟。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 演示控制

- 下一页：`→`、`PageDown`、空格
- 上一页：`←`、`PageUp`
- 首尾页：`Home`、`End`
- 讲者备注：`N`
- 目录：`O`
- 关闭浮层：`Escape`
- 手机：左右滑动

## 证据边界

项目只使用用户提供的悟空形象、钉钉 Logo 和 DWS 图片。产品界面与业务结果证据没有伪造，相关页面保留真实截图占位；详见网页“资料”面板或 `public/assets/截图素材清单.md`。
