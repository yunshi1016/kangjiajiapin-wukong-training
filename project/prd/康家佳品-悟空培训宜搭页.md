# 康家佳品·悟空培训宜搭页 PRD

## 基本信息

- 目标组织：广东帮仁数字科技有限公司
- corpId：`ding53491c25196631b535c2f4657eb6378f`
- 应用名称：康家佳品·悟空培训
- 页面名称：让 AI 真正帮你干活
- 视觉方案：沿用已确认的 A 版浅色钉钉蓝视觉

## MVP 范围与版本边界

### V1 必做

- 在宜搭自定义页面中完整呈现现有 39 页培训 PPT。
- 保留每页主标题、Obsidian 逐页副标题、钉钉 Logo、悟空形象和员工情绪对比。
- 保留 6 段录屏并支持页面内播放。
- 支持方向键、PageUp、PageDown、空格、数字键快速跳页、触摸滑动、底部导航和全屏。
- 首次打开时预加载图片，并对视频提供明确加载状态和失败重试。
- PC 端按 16:9 画布缩放，移动端保持内容完整可读。
- 隐藏宜搭默认顶部导航，作为独立演示页面使用。

### V1 不做

- 不引入表单数据、流程审批、统计报表或连接器。
- 不提供在线编辑 PPT 内容的后台管理页。
- 不面向未登录的互联网匿名用户公开资源。

### V2 候选

- 演讲者备注视图和双屏演讲模式。
- 培训反馈、签到与问题收集表单。
- 录屏资源按培训版本进行后台维护。

## 目标用户与权限

- 讲师：打开页面、翻页、全屏和播放视频。
- 广东帮仁组织内学员：在已登录宜搭的情况下查看课件和视频。
- 宜搭应用管理员：维护页面源码、访问权限和后续版本。
- V1 页面默认使用组织内访问，不授予匿名公网访问。

## 核心用户旅程

1. 用户从钉钉或浏览器打开宜搭页面链接。
2. 页面首屏立即可见，同时在后台准备图片和视频资源。
3. 用户通过键盘、鼠标或触摸在 39 页之间导航。
4. 到达录屏页后直接点击播放，无需重新访问 GitHub Pages。
5. 素材失败时页面显示可理解的错误信息和重试入口。
6. 完成培训后可直接关闭页面，无业务数据写入。

成功标准：39 页顺序正确；全部图片可见；6 段视频可播放；键盘、触摸和全屏均有效；页面不依赖 GitHub Pages 资源。

## 页面配置与内容结构

- 页面类型：自定义展示页，dashboard / chromeless 模式。
- 内容结构：封面、定位与架构、核心技术概念、四大业务板块场景、能力回顾、互动、结语、4 页附录。
- 固定品牌元素：钉钉 Logo、康家佳品·悟空专场、页码。
- 素材：本项目 `ppt-assets/` 内的插画、视频封面与 6 段录屏。
- 页面不使用业务表单，因此无字段配置和 FIELDS 映射。

## 流程与状态机

- 页面状态：初始化 → 图片准备中 → 视频准备中 → 全部就绪。
- 异常状态：单项失败 → 自动重试 → 仍失败则显示手动重试。
- 幻灯片状态：当前页索引 0–38，翻页操作不得超出边界。
- 视频状态：未加载、加载中、可播放、播放中、失败；离开当前页时暂停。

## 数据关联与约束

- V1 不创建业务数据表，不写入宜搭表单数据。
- 所有 appType、formUuid 和素材映射写入项目 `.cache/`，不写入本 PRD。
- 图片与视频必须使用宜搭侧可访问资源或页面内资源，不允许回退到 GitHub Pages。
- 资源文件名保持唯一；同名覆盖前需核对内容哈希。
- 页面初始化和重复点击重试必须幂等，避免重复注册事件和重复占用 Blob URL。

## 交互与验收标准

- 页面加载后 1 秒内出现首屏或明确加载反馈，不允许长时间白屏。
- 方向键、PageUp、PageDown、空格可翻页，数字键可跳页。
- 移动端左右滑动可翻页，所有图片使用 `objectFit: contain`。
- 6 个视频都显示 controls，并可在对应页面播放；离开页面后自动暂停。
- 每个可见按钮都有真实事件处理器；卸载时清理键盘、触摸、全屏、hash 和计时器监听。
- 发布前必须通过 `openyida check-page` 与 `openyida compile`。
- 首次发布使用 `--health-check`，发布后回读页面配置并进行浏览器首屏与翻页验证。
